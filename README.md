# Лабораторная работа № 7 — JavaScript и DOM

**Вариант 24:** анализ динамики показателей финансовой отчётности предприятий.

Проект основан на блоге из лабораторной работы № 6 и дополняет его заданиями по JavaScript:

- `articles/static/js/helloworld.js` — массив студентов, вывод через `console.log`, форматирование таблицы, фильтрация по группе и среднему баллу;
- `articles/static/js/fold-post.js` — сворачивание и разворачивание содержимого каждой статьи с помощью DOM и CSS-класса `folded`;
- `articles/templates/archive.html` — подключение JS-файлов, элементы фильтрации и кнопки «свернуть»;
- `articles/static/css/article.css` — оформление элементов лабораторной № 7 и CSS-правила для свёрнутого поста.

## Запуск на Windows

Команды выполняются в PowerShell. Виртуальное окружение необязательно, если Django уже установлен в используемом Python.

```powershell
cd "C:\Users\<USER>\Desktop\Мтуси актуальные пары\Прикладные ИС\lab7\blog"
python -m pip install -r ..\requirements.txt
python manage.py migrate
python manage.py check
python manage.py test articles
python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. JavaScript работает на странице архива. Результаты начального вывода массива и таблицы можно посмотреть в Developer Tools → Console; загрузку файлов — в Developer Tools → Network (фильтр JS).

## Как проверить фильтрацию студентов

На странице архива есть поле для ввода группы и поле порога среднего балла. Введите значение и нажмите соответствующую кнопку. Результат будет показан на странице и выведен в консоль. Фильтр среднего балла выбирает студентов, чей средний балл **строго выше** введённого порога.

## Как проверить сворачивание статей

В карточке каждой статьи нажмите «свернуть». Кнопка изменится на «развернуть», а автор, дата и текст скроются. Повторное нажатие восстановит содержимое. Сворачивание реализовано изменением класса `folded` родительского элемента `.one-post`, а сокрытие элементов выполняется в CSS.

## База данных

Локальная база данных `blog/db_project_name` не включена в архив и должна создаваться командой `python manage.py migrate`. Не добавляйте локальную базу данных, файлы `.env`, пароли или виртуальное окружение в публичный Git-репозиторий.
