## 1. Цель работы

Изучить базовые возможности JavaScript, работу с массивами и функциями, вывод данных в консоль, фильтрацию элементов массива, а также изменение HTML-документа с помощью DOM и CSS-классов.

## 2. Массив студентов и вывод данных

В файле `articles/static/js/helloworld.js` создан массив `groupmates`. Каждый объект содержит имя, фамилию, группу и массив оценок. Массив выводится с помощью `console.log()`, а функция `printStudents()` печатает отформатированную таблицу в консоль. Форматирование строк выполняется вспомогательной функцией `rpad()`.

## 3. Фильтрация студентов

Реализованы две функции:

- `filterStudentsByGroup()` — отбирает студентов по введённому названию группы;
- `filterStudentsByAverage()` — вычисляет средний балл студента и оставляет только тех, чей средний балл строго выше заданного пользователем значения.

Значения можно ввести в поля на странице архива. Результаты выводятся на страницу и дополнительно в консоль разработчика.

## 4. Работа с DOM: сворачивание статей

В архиве для каждой статьи добавлена кнопка с классом `fold-button`. Скрипт `articles/static/js/fold-post.js` назначает обработчик события `click`. При нажатии класс `folded` добавляется или удаляется у родительского элемента `.one-post`.

Скрытие автора, даты публикации и текста выполняется через CSS-селекторы `.one-post.folded .article-author`, `.one-post.folded .article-created-date` и `.one-post.folded .article-text`. При повторном нажатии исходное отображение восстанавливается, а подпись кнопки меняется.

## 5. Подключение JavaScript

Файлы `helloworld.js` и `fold-post.js` размещены в `articles/static/js/` и подключены к шаблону `archive.html` с помощью шаблонного тега Django `{% static %}`. Оба скрипта подключены ближе к закрывающему тегу `</body>`. Их загрузку можно подтвердить во вкладке Network инструментов разработчика, а результаты выполнения — во вкладке Console.
